# DB 변경 기록

FTP로 파일만 올리면 되는 변경인지, **`db/setup.php`를 한 번 더 열어야 하는 변경인지**를
구분하기 위한 기록입니다. 사이트 화면 변경 기록은 프로젝트 맨 위 `CHANGELOG.md`를 보세요.

## 어떻게 쓰나요

1. FTP로 파일을 올린다
2. 아래 목록에서 **내가 마지막으로 setup.php를 실행한 날짜 이후**에 `setup.php 실행` 표시가
   붙은 항목이 하나라도 있으면 → 브라우저에서 `내사이트주소/db/setup.php`를 한 번 연다
3. 없으면 → 아무것도 안 해도 됨

`setup.php`는 **몇 번을 실행해도 안전합니다.** 이미 있는 테이블·칼럼은 건너뛰고,
없는 것만 새로 만듭니다. 기존에 입력해둔 데이터는 지워지지 않습니다.

> 마지막으로 setup.php를 실행한 날짜를 여기에 적어두면 편합니다 →
> **마지막 실행: (날짜를 적어주세요)**

## 지금 쓰고 있는 테이블 (총 10개)

| 테이블 | 무엇이 들어있나 | 어디서 쓰나 |
|---|---|---|
| `yj_admin_users` | 로그인 계정(아이디·비밀번호·역할·실명) | 관리자 로그인 전체 |
| `yj_notices` | 공지사항 글 | 공지사항 페이지·관리 |
| `yj_license_data` | 면허 탐색기 데이터(과정·시간·수강료) 통째로 | 면허 탐색기·관리 |
| `yj_staff` | 임직원(이름·MBTI·근무형태·사진·인사말) | 홈 강사진 캐러셀·관리 |
| `yj_shuttle_riders` | 셔틀 탑승자 명단(날짜별 사람) | 셔틀 명단 관리 |
| `yj_shuttle_slots` | 셔틀 운행 편성(날짜별 차량·출발시간) | 셔틀 명단 관리 |
| `yj_student_schedule` | 학사서버에서 받아온 예약 일정 사본 | 내 일정 조회 |
| `yj_contact_messages` | 홈페이지 문의 메시지 + 면허 탐색기 상담 신청(과정·연락 가능 시간) | 문의 관리 |
| `yj_written_exam` | 필기시험 (학생당 최신 한 건) | 안내장 앱(guide-print) 저장 + 필기시험 조회 페이지 |
| `yj_login_attempts` | 관리자 로그인 실패 기록(IP·시각, 하루 지나면 정리) | 로그인 시도 횟수 제한 |

`yj_`는 `config.php`의 `table_prefix` 값입니다. 설정을 바꿨다면 그 값으로 읽으세요.

### 주의: 기본 데이터 파일은 최초 1회만 반영됩니다

`db/license_default_data.json`, `notice_default_data.json`, `staff_default_data.json`은
**해당 테이블이 완전히 비어 있을 때만** DB에 들어갑니다. 이미 데이터가 있는 상태에서
이 파일들을 고쳐서 올리고 setup.php를 실행해도 **아무 일도 일어나지 않습니다.**
이미 운영 중인 내용을 고치려면 관리자 화면(면허 탐색기 관리 등)에서 수정해야 합니다.

### 2026-09-23 — `0e94a5d` · setup.php 실행 권장 (안 해도 자동 보강됨)

`yj_contact_messages`에 면허 탐색기 상담 신청용 칼럼 6개 추가 —

처음 쓸 때 칼럼이 없으면 그 자리에서 만들어지므로, setup.php를 깜빡해도 동작은
합니다.

### 2026-09-23 — `b57a179`·`2fa3e09`·`0de0fc2` · setup.php 실행 권장 (안 해도 자동 보강됨)

- `yj_admin_users`에 `session_version` 칼럼 추가 — 비밀번호 변경·역할 변경·
  계정 삭제 시 올라가서, 그 전에 로그인해 있던 세션을 바로 끊습니다.

**배포 순서 주의가 필요 없도록** 관리자 로그인 요청 때 두 항목이 없으면 그 자리에서

돌리는 순간 사이에 로그인이 막히고, setup.php도 이제 관리자로 로그인해야 열 수
있어서 스스로 풀 수 없게 됩니다.

**setup.php 자체도 바뀌었습니다 (`ecf26e3`·`f8c31ed`)**: 최고관리자 계정이 이미 있으면
**최고관리자로 로그인한 상태에서만** 열립니다(예전엔 누구나 열어서 계정을 만들거나
비밀번호를 덮어쓸 수 있었음). office1~3 공용 계정도 더 이상 만들지 않습니다 —
이미 있는 office1~3는 관리자 화면 "계정 관리"에서 지우시면 됩니다.

### 파일만 바뀐 변경 (setup.php 실행 불필요)
