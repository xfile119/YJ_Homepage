# YJ_Homepage

영진자동차운전전문학원 홈페이지 (정적 HTML/CSS/JS)

## 폴더 구조

```
/index.html         홈
/about.html          학원소개 (인사말, 강사진 캐러셀) — 수강생에게 불필요한 연혁·시설 소개는 의도적으로 제외
/license-guide.html      면허 취득 안내 (보유면허·목표면허 선택 → 의무교육시간·예상비용 계산) — 교육과정 안내를 겸함
/driving-lessons.html     도로연수 안내 (승용차&SUV·화물트럭·대형버스, 1:1 맞춤 연수 소개)
/education-hours.html     교육시간 안내 (학과교육 시간표: 1·2종 보통·2종소형/대형·특수면허별 요일·시간 안내, 정적 페이지)
/notice.html         공지사항 목록 (예시 데이터)
/notice-detail.html      공지사항 상세보기 (?id=.. 로 개별 게시글 본문·이미지 표시)
/location.html        오시는길 (주소, 지도, 셔틀버스 노선)
/contact.html         상담문의 (카카오톡·네이버 톡톡)
/privacy.html         개인정보처리방침 (기존 사이트 내용 이식)
/admin.html          관리자 모드 진입 허브 (비공개, 메뉴에 없음)
/admin-notice.html      공지사항 추가·수정·삭제 도구 (비공개, DB 연동)
/admin-license.html      면허가이드 수강료·교육시간 편집 도구 (비공개, DB 연동)

/api/              PHP API (notices.php, license-data.php, staff.php, upload.php, auth.php) — DB 있는 서버에서만 동작

/config.example.php     DB 접속정보 템플릿 (복사해서 config.php로 만들고 실제 값 입력, git에는 안 올라감)
```

※ 기존에 있던 `courses.html`(교육과정 페이지)은 삭제되었습니다. 교육과정/수강료 안내는 `license-guide.html` 하나로 통합되었습니다.

빌드 과정 없이 각 `.html` 파일을 그대로 웹 서버(또는 GitHub Pages 등)에 올리면 동작합니다.

## 관리자 모드 (DB 연동)

`admin.html`(진입 허브) + `admin-notice.html`(공지사항) + `admin-license.html`(수강료·교육시간) + `admin-staff.html`(임직원)은 서버의 PHP API(`api/*.php`)와 MySQL DB로 동작합니다. 네 파일 모두 메뉴·검색엔진에 노출되지 않는 비공개 페이지(`noindex`)입니다.

- **로그인**: `admin.html`에서 아이디/비밀번호를 입력하면 서버가 DB에 저장된 해시와 대조합니다(`password_hash`/`password_verify`, PHP 세션 기반). 계정은 `db/setup.php`에서 최초 1회 생성합니다.
- **저장 방식**: 각 관리 화면에서 값을 수정하고 "저장하기"를 누르면 즉시 DB에 쓰고, 홈페이지(`notice.html`/`index.html`/`license-guide.html`/`about.html`)는 방문할 때마다 `api/notices.php`, `api/license-data.php`, `api/staff.php`를 호출해 최신 데이터를 그려줍니다. 다운로드/재배포가 필요 없습니다.
- **PHP가 없는 곳(GitHub Pages 등)에서는?** `api/*.php`가 실행되지 않으니 `fetch`가 실패하고, 각 페이지는 자동으로 원래 있던 예시 데이터를 그대로 보여줍니다(정상 동작, 에러 아님). 관리자 화면도 "서버(api)에 접속할 수 없습니다" 메시지만 뜨고 조용히 멈춥니다.
- `admin-notice.html`: 공지사항 목록을 표로 편집(추가/삭제/순서변경/뱃지)하고 저장하면, `notice.html`(전체 목록)과 `index.html`(상위 3개 미리보기)에 한 번에 반영됩니다.
- `admin-license.html`: 학원 연락처, 응시료, 39개 케이스별 교육시간·수강료를 편집해 저장하면 `license-guide.html`에 바로 반영됩니다. 상단 "수강료 자동계산 요금표"에서 학과교육비(공통 단가)와 면허 종류별 기능/도로주행 단가를 설정하면, "자동" 모드로 설정된 케이스는 교육시간 × 단가로 수강료가 자동 계산됩니다. 요금표 공식으로 설명되지 않는 특수 케이스만 "수동"으로 표시해 직접 입력합니다.
- `admin-staff.html`: 임직원을 카드 단위로 추가·삭제·순서변경하고, 사진·이름·성향(MBTI)·인사말(선택, 60자 이내)·근무형태(강사/사무실/셔틀)·강의종별(학과교육/기능교육/도로주행/대형·특수/도로연수, 복수 선택 가능)을 입력해 저장합니다. "근무형태=강사 또는 사무실"인 인원만 `about.html` 하단의 강사진 캐러셀 대상이 되고(셔틀 인력은 내부 명단 관리용), 그 중에서도 방문자가 "강사진"/"사무실" 탭으로 골라서 봅니다. 사진은 `api/upload.php`로 업로드되어 `uploads/staff/`에 저장됩니다. 몇 명을 등록하든 개수 제한은 없습니다 — 인원이 많아지면(성수기 강사 충원 등) 캐러셀이 자동으로 사진 크기와 배치 반지름을 줄여 겹치지 않게 배치합니다(4명까지 150px, 이후 서서히 축소되어 최소 70px까지).
  - **about.html 캐러셀 사용법**: "강사진"/"사무실" 탭을 눌러 조직을 고르면 해당 인원만 캐러셀에 나타납니다(선택한 조직에 등록된 인원이 없으면 안내 문구만 표시). 원형 사진을 마우스/터치로 좌우 드래그하면 3D로 회전하며 다음 인물로 전환됩니다. 점(dot) 클릭이나 캐러셀에 포커스 후 방향키(←/→)로도 이동할 수 있고, 아래에 이름·강의종별·MBTI·인사말(입력했을 때만)이 표시됩니다. 등록된 강사·사무실 인원이 전혀 없거나 DB 연동 전(정적 호스팅)에는 탭 없이 예시 팀 4개로 자동 대체됩니다.

## 카페24 배포 가이드 (DB 연동해서 서버에서 동작시키기)

기존 www.yjcdrive.co.kr 호스팅 계정(카페24) 안에 새 사이트를 **`yjcdrive.co.kr/new` 하위 경로**로 올리는 방법입니다. 기존 홈페이지·기존 DB는 전혀 건드리지 않습니다.

### 1. 파일 준비
1. 이 저장소의 `config.example.php`를 복사해서 `config.php`로 저장합니다. (이 파일은 `.gitignore`에 등록되어 있어 저장소에는 절대 올라가지 않습니다.)
2. `config.php`에 실제 DB 정보를 입력합니다:
   ```php
   return [
       'db_host' => 'localhost',
       'db_name' => '실제 DB 이름',
       'db_user' => '실제 DB 사용자명',
       'db_pass' => '실제 DB 비밀번호',
       'table_prefix' => 'yj_',   // 기존 DB를 같이 쓸 경우 테이블 이름 충돌 방지용
   ];
   ```

### 2. DB 준비 (카페24)
카페24 표준 웹호스팅은 보통 **DB 1개**만 기본 제공됩니다(추가 구매 가능). 두 가지 중 편한 방법을 쓰세요.
- **여유 DB가 있다면**: 카페24 호스팅센터 → 나의서비스관리에서 새 DB를 만들고, 그 접속정보를 `config.php`에 입력합니다.
- **기존 DB 1개만 있다면**: 문제 없습니다. 기존 사이트가 쓰던 DB 접속정보(예전 `dbconfig.php`에 있던 값)를 그대로 `config.php`에 입력하되, `table_prefix`를 `yj_`(또는 원하는 값)로 유지하세요. 새 테이블(`yj_notices` 등)만 추가로 생성되고 기존 테이블은 전혀 건드리지 않습니다.
- 카페24는 보안상 phpMyAdmin을 기본 제공하지 않습니다 — 아래 3단계의 `db/setup.php`가 phpMyAdmin 없이 테이블을 자동으로 만들어주므로 신경 쓰지 않아도 됩니다.

### 3. 업로드
1. 카페24 호스팅센터 → FTP 정보로 접속(FTP 클라이언트 또는 웹FTP/파일관리자 사용).
2. 웹 루트 아래 `new` 폴더를 만들고, 이 저장소의 **모든 파일**(방금 만든 `config.php` 포함)을 그 안에 업로드합니다.

### 4. 설치 스크립트 실행 (최초 1회)
1. 브라우저에서 `https://yjcdrive.co.kr/new/db/setup.php` 접속.
2. 자동으로 테이블 생성 + 공지사항/면허가이드 기본 데이터가 채워집니다.
3. 화면에 나오는 폼에 원하는 **관리자 아이디/비밀번호**(8자 이상)를 입력하고 "관리자 계정 만들기".
4. 완료 메시지가 뜨면 **`db/setup.php` 파일을 서버에서 삭제**하세요 (다시 실행되면 안 되므로).

## license-guide.html (면허 취득 안내 위젯)

사용자가 제공한 위젯 파일(`__embed.html`)을 그대로 이식하고, 홈페이지 색상 변수(`css/style.css`의 `--color-*`)에 맞춰 위젯 내부의 색상 토큰만 재매핑했습니다. 레이아웃·계산 로직·데이터는 원본 그대로입니다.

- **데이터 수정 방법**: `license-guide.html` 안의 `<script>` 블록 맨 위 `var DATA = {...}` 부분(연락처, 시험 응시료, 케이스별 교육시간/수강료)을 직접 고치거나, 위의 `admin-license.html`을 사용하세요.
- 위젯에 입력된 실제 주소·전화번호는 사이트 전체(footer, 오시는길, 상담문의)에도 반영했고, 4개 주요 과정의 수강료·교육시간도 이 데이터를 기준으로 갱신했습니다.
- **중요한 데이터 원칙**: 각 케이스의 `hours.{hak,gi,doro}` 첫 번째 숫자가 0이면(화면에 "0시간"으로 표시되면) 같은 항목의 `cost` 값도 반드시 0이어야 하고, 시험 응시료도 자동으로 면제 처리됩니다(0시간인데 비용이 발생하던 TM-01~04, B1-06 케이스의 학과/기능교육비 오류를 이 원칙에 맞춰 수정했습니다). `hours` 배열은 `[시간, 시간]`처럼 같은 값 2개로 저장되며(과거 데이터에 `[0,3]`처럼 서로 다른 값이 섞여 있던 것이 오류의 원인이었습니다), `admin-license.html`에서 수정하면 항상 이 형태로 저장되니 앞으로는 이런 불일치가 생기지 않습니다.

## 사이트 구조 단순화 (2026-09)

수강생이 실제로 궁금해하는 건 "과정 · 비용 · 기간 · 교육시간 · 준비물 · 시험일정" 정도라는 판단 아래 아래처럼 정리했습니다.

- **상단 메뉴를 4개로 축소**: 홈 · 면허안내 · 교육시간 · 상담문의. 기존 학원소개·도로연수·공지사항·오시는길은 상단 메뉴에서 빠지고 footer(바로가기)와 홈 하단 "학원소개 더 보기" 카드로 이동했습니다. 페이지 자체는 삭제하지 않았습니다.
- **`license-guide.html` 결과 화면 확장**: 기존에는 교육시간·수강료·시험응시료만 보여줬는데, 여기에 4가지를 더 추가했습니다.
  - **취득 과정**: 학과교육→장내기능교육·시험→도로주행교육·시험→면허증 발급 흐름을 케이스별 `hours` 값(0시간이면 "면제"로 표시)으로 자동 생성.
  - **예상 소요기간**: 교육시간 합계를 기준으로 한 대략적인 기간 추정치(실제와 다를 수 있음을 명시).
  - **교육 가능 시간**: `education-hours.html`의 실제 시간표를 면허 종류별로 인라인 표시 + 전체 시간표 링크.
  - **준비물 / 시험 일정**: 학원 공통 안내(신분증, 증명사진, 신체검사 등)와, 해당 케이스에 실제 응시료가 있는 시험만 안내.
  - 위 4가지는 모두 기존 `DATA`(hours/cost)에서 파생되거나, 명확히 "추정치/상담 시 안내"로 라벨링된 일반 안내문이라 실제 수치를 새로 지어내지 않았습니다.
- **색상 톤 조정**: "따뜻하지만 무거워 보인다"는 피드백에 따라 `--color-primary-dark`를 밝게 하고(`#664e37`→`#7a5c42`), 히어로/페이지헤더 그라데이션에서 가장 어두운 톤을 빼고, 푸터 배경을 거의 검정에 가까운 `#362a1e`에서 `--color-primary-dark`로 교체했습니다.
