# YJ_Homepage

영진자동차운전전문학원 홈페이지 (정적 HTML/CSS/JS)

## 폴더 구조

```
/index.html      홈
/about.html       학원소개 (인사말, 연혁, 시설, 강사진)
/courses.html      교육과정 (1종보통/2종보통/1종대형/2종소형(이륜)/도로연수)
/notice.html      공지사항 목록 (예시 데이터)
/location.html     오시는길 (주소, 지도, 셔틀버스 노선)
/contact.html      상담문의 (상담 신청 폼)
/css/style.css     전체 스타일시트
/js/main.js       모바일 메뉴, 스크롤 헤더, 상담 폼 검증
```

빌드 과정 없이 각 `.html` 파일을 그대로 웹 서버(또는 GitHub Pages 등)에 올리면 동작합니다.

## 실제 운영 전 반드시 교체해야 할 항목

각 페이지에 `[입력해주세요]` 표시 또는 <span class="data-flag"> 형태의 주황색 배지로 표시해 두었습니다. 텍스트 검색(`grep -r "입력\|교체 필요\|data-flag" .`)으로 위치를 모두 찾을 수 있습니다.

1. **주소** — 모든 페이지 하단(footer)과 `location.html`, `contact.html`에 "광주광역시 [상세주소를 입력해주세요]"로 표시됨. 실제 도로명주소로 교체.
2. **팩스번호, 이메일 주소** — footer 및 `contact.html`, `location.html`.
3. **사업자등록번호, 대표자명** — 모든 페이지 footer 하단.
4. **교육과정별 정확한 수강료** — `courses.html`, `index.html` (현재는 예시 금액이며 "(예시)"로 표시).
5. **연혁(History)** — `about.html`의 타임라인 항목 전체가 예시입니다. 실제 설립연도와 주요 연혁으로 교체하세요.
6. **강사진 정보** — `about.html`. 현재는 팀 단위 placeholder만 있습니다. 실제 강사 성함/약력/사진으로 교체 권장.
7. **공지사항** — `notice.html`, `index.html`의 미리보기. 전부 예시 게시글입니다. 실제 게시판 시스템(또는 CMS) 연동 전까지는 직접 HTML을 수정해 관리해야 합니다.
8. **셔틀버스 노선 및 시간표** — `location.html`. 실제 운행 노선/정류장/시간으로 교체.
9. **오시는 길 지도** — `index.html`, `location.html`의 지도 영역은 현재 placeholder입니다. 카카오맵 또는 네이버지도 API 키를 발급받아 `<iframe>` 또는 JS SDK로 교체해야 실제 지도가 표시됩니다.
10. **상담 신청 폼 백엔드 연동** — `contact.html`의 폼은 현재 클라이언트 측 검증 후 화면에 "접수 완료" 메시지만 보여줍니다. 실제 이메일 발송/DB 저장이 필요하다면 서버 API(또는 Formspree, Google Forms 등 외부 폼 서비스) 연동이 필요합니다.
11. **카카오톡 채널 링크** — `contact.html`.
12. **파비콘/실제 사진** — 현재 로고와 이미지는 모두 SVG 아이콘으로 대체되어 있습니다. 실제 학원 사진, 로고, 파비콘 파일을 `/images` 폴더에 추가하고 각 페이지에서 연결하세요.
