# YJ_Homepage

영진자동차운전전문학원 홈페이지 (정적 HTML/CSS/JS)

## 폴더 구조

```

/about.html          학원소개 (인사말) — 강사진 캐러셀은 홈으로 이동했고, 연혁·시설 소개는 의도적으로 제외
```

## 관리자 모드 (DB 연동)

`admin.html`(진입 허브) + `admin-notice.html`(공지사항) + `admin-license.html`(수강료·교육시간) + `admin-staff.html`(임직원)은 서버의 PHP API(`api/*.php`)와 MySQL DB로 동작합니다. 네 파일 모두 메뉴·검색엔진에 노출되지 않는 비공개 페이지(`noindex`)입니다.

- **로그인**: `admin.html`에서 아이디/비밀번호를 입력하면 서버가 DB에 저장된 해시와 대조합니다(`password_hash`/`password_verify`, PHP 세션 기반). 계정은 `db/setup.php`에서 최초 1회 생성합니다.
- **저장 방식**: 각 관리 화면에서 값을 수정하고 "저장하기"를 누르면 즉시 DB에 쓰고, 홈페이지(`notice.html`/`index.html`/`license-guide.html`/`index.html`)는 방문할 때마다 `api/notices.php`, `api/license-data.php`, `api/staff.php`를 호출해 최신 데이터를 그려줍니다. 다운로드/재배포가 필요 없습니다.
- **PHP가 없는 곳(GitHub Pages 등)에서는?** `api/*.php`가 실행되지 않으니 `fetch`가 실패하고, 각 페이지는 자동으로 원래 있던 예시 데이터를 그대로 보여줍니다(정상 동작, 에러 아님). 관리자 화면도 "서버(api)에 접속할 수 없습니다" 메시지만 뜨고 조용히 멈춥니다.
- `admin-notice.html`: 공지사항 목록을 표로 편집(추가/삭제/순서변경/뱃지)하고 저장하면, `notice.html`(전체 목록)과 `index.html`(상위 3개 미리보기)에 한 번에 반영됩니다.
- `admin-license.html`: 학원 연락처, 응시료, 36개 케이스별 교육시간·수강료를 편집해 저장하면 `license-guide.html`에 바로 반영됩니다. 상단 "수강료 자동계산 요금표"에서 학과교육비(공통 단가)와 면허 종류별 기능/도로주행 단가를 설정하면, "자동" 모드로 설정된 케이스는 교육시간 × 단가로 수강료가 자동 계산됩니다. 요금표 공식으로 설명되지 않는 특수 케이스만 "수동"으로 표시해 직접 입력합니다. **현재는 36개 케이스 모두 공식과 일치해 기본값이 전부 "자동"입니다**(`MANUAL_DEFAULT_CODES`가 빈 배열).
- `admin-staff.html`: 임직원을 카드 단위로 추가·삭제·순서변경하고, 사진·이름·성향(MBTI)·인사말(선택, 60자 이내)·근무형태(강사/사무실/셔틀)·강의종별(학과교육/기능교육/도로주행/대형·특수/도로연수, 복수 선택 가능)을 입력해 저장합니다. "근무형태=강사 또는 사무실"인 인원만 홈(`index.html`)의 강사진 캐러셀 대상이 되고(셔틀 인력은 내부 명단 관리용), 그 중에서도 방문자가 "강사진"/"사무실" 탭으로 골라서 봅니다. 사진은 `api/upload.php`로 업로드되어 `uploads/staff/`에 저장됩니다. 몇 명을 등록하든 개수 제한은 없습니다 — 인원이 많아지면(성수기 강사 충원 등) 캐러셀이 자동으로 사진 크기와 배치 반지름을 줄여 겹치지 않게 배치합니다(4명까지 150px, 이후 서서히 축소되어 최소 70px까지).
  - **홈 캐러셀 사용법**: "강사진"/"사무실" 탭을 눌러 조직을 고르면 해당 인원만 캐러셀에 나타납니다(선택한 조직에 등록된 인원이 없으면 안내 문구만 표시). 원형 사진을 마우스/터치로 좌우 드래그하면 3D로 회전하며 다음 인물로 전환됩니다. 점(dot) 클릭이나 캐러셀에 포커스 후 방향키(←/→)로도 이동할 수 있고, 아래에 이름·강의종별·MBTI·인사말(입력했을 때만)이 표시됩니다. 등록된 강사·사무실 인원이 전혀 없거나 DB 연동 전(정적 호스팅)에는 탭 없이 예시 팀 4개로 자동 대체됩니다.

## 셔틀(차량 운행) 명단 — 개인정보 취급 주의

기존에 종이로 쓰시던 "차량 운행 명단" 양식을 그대로 옮긴 기능입니다. **이름·연락처라는 실제 개인정보를 다루므로** 아래 설계를 지키고 있습니다.

- **작성**: `admin-shuttle.html` (관리자 로그인 필요). 날짜를 고르고 시간대(08:30 / 13:30 …)별로 성명·장소·연락처를 입력합니다. 종이 양식처럼 2단으로 배치되고, "인쇄" 버튼으로 기사님께 드릴 종이 명단을 뽑을 수 있습니다. 저장은 **그 날짜의 명단 전체를 교체**하며, 성명이 빈 줄은 저장하지 않습니다.
- **조회**: `shuttle.html` (수강생용, 로그인 없음). 이름 + 전화번호 뒷 4자리로 조회합니다.
- **조회에 쓰이는 이름·전화번호는 별도로 입력하는 게 아니라, 사무실에서 명단에 적은 그 값입니다.** 즉 직원이 명단에 "홍길동 / 운남5단지 / 010-1234-5678"을 넣어 저장하면, 수강생이 "홍길동 + 5678"로 조회했을 때 그 행이 매칭됩니다. 연락처 칸은 기사님 연락용이자 **조회의 열쇠**이므로 비워두면 그 수강생은 조회할 수 없습니다.
  - 이름은 **공백을 무시하고** 비교합니다("홍 길동"으로 적혀 있어도 "홍길동"으로 조회됨).
  - 전화번호는 하이픈 유무와 무관하게 **뒷 4자리**만 맞으면 됩니다.
  - 다만 이름의 오타(김영희/김영히)까지는 걸러주지 못하니, 명단 입력 시 수강 신청서와 같게 적어야 합니다.
- **`api/shuttle.php`의 보호 장치** — 명단 전체가 외부로 나가지 않도록 다음을 지킵니다.
  1. 전체 명단을 돌려주는 `GET`은 **관리자 로그인 필수**입니다. 수강생용 조회는 `action=lookup` 하나뿐이고, **일치한 본인의 행만** 반환합니다.
  2. 이름과 전화번호 뒷 4자리가 **모두** 맞아야 합니다.
  3. **오늘 이후 날짜만** 반환합니다(지난 기록 조회 차단).
  4. 이름만 맞고 번호가 틀린 경우와 아예 없는 경우의 **응답을 구분하지 않습니다**(명단에 누가 있는지 유추 방지).
  5. 세션당 **10분에 15회**로 조회 횟수를 제한해 무작위 대입을 늦춥니다.
- 검색엔진에 노출되지 않도록 `shuttle.html`에는 `noindex`를 걸어두었습니다.
- **한계**: 이름+뒷4자리는 편의를 위한 최소한의 확인 수단이라, 지인처럼 두 정보를 아는 사람은 조회할 수 있습니다. 더 엄격히 막으려면 회원가입/문자 인증이 필요한데 지금 사이트 규모에는 과하다고 판단했습니다. 필요해지면 알려주세요.

## 카페24 배포 가이드 (DB 연동해서 서버에서 동작시키기)

기존 www.yjcdrive.co.kr 호스팅 계정(카페24) 안에 새 사이트를 **`yjcdrive.co.kr/new` 하위 경로**로 올리는 방법입니다. 기존 홈페이지·기존 DB는 전혀 건드리지 않습니다.

### 1. 파일 준비
1. 이 저장소의 `config.example.php`를 복사해서 `config.php`로 저장합니다. (이 파일은 `.gitignore`에 등록되어 있어 저장소에는 절대 올라가지 않습니다.)
2. `config.php`에 실제 DB 정보를 입력합니다:
   ```php
   return [
       'db_host' => 'localhost',
       'db_name' => '실제 DB 이름',
       'db_user' => '실제 DB 사용자명',
       'db_pass' => '실제 DB 비밀번호',
       'table_prefix' => 'yj_',   // 기존 DB를 같이 쓸 경우 테이블 이름 충돌 방지용
   ];
   ```

### 2. DB 준비 (카페24)
카페24 표준 웹호스팅은 보통 **DB 1개**만 기본 제공됩니다(추가 구매 가능). 두 가지 중 편한 방법을 쓰세요.
- **여유 DB가 있다면**: 카페24 호스팅센터 → 나의서비스관리에서 새 DB를 만들고, 그 접속정보를 `config.php`에 입력합니다.
- **기존 DB 1개만 있다면**: 문제 없습니다. 기존 사이트가 쓰던 DB 접속정보(예전 `dbconfig.php`에 있던 값)를 그대로 `config.php`에 입력하되, `table_prefix`를 `yj_`(또는 원하는 값)로 유지하세요. 새 테이블(`yj_notices` 등)만 추가로 생성되고 기존 테이블은 전혀 건드리지 않습니다.
- 카페24는 보안상 phpMyAdmin을 기본 제공하지 않습니다 — 아래 3단계의 `db/setup.php`가 phpMyAdmin 없이 테이블을 자동으로 만들어주므로 신경 쓰지 않아도 됩니다.

### 3. 업로드
1. 카페24 호스팅센터 → FTP 정보로 접속(FTP 클라이언트 또는 웹FTP/파일관리자 사용).
2. 웹 루트 아래 `new` 폴더를 만들고, 이 저장소의 **모든 파일**(방금 만든 `config.php` 포함)을 그 안에 업로드합니다.

### 4. 설치 스크립트 실행 (최초 1회)
1. 브라우저에서 `https://yjcdrive.co.kr/new/db/setup.php` 접속.
2. 자동으로 테이블 생성 + 공지사항/면허가이드 기본 데이터가 채워집니다.
3. 화면에 나오는 폼에 원하는 **관리자 아이디/비밀번호**(8자 이상)를 입력하고 "관리자 계정 만들기".
4. 완료 메시지가 뜨면 **`db/setup.php` 파일을 서버에서 삭제**하세요 (다시 실행되면 안 되므로).

### 5. 확인
- `https://yjcdrive.co.kr/new/admin.html`에서 방금 만든 아이디/비밀번호로 로그인 → 공지사항/수강료 관리 화면이 열리는지 확인.
- `https://yjcdrive.co.kr/new/notice.html`, `/new/license-guide.html`이 정상적으로 데이터를 보여주는지 확인.
- 문제가 있으면 브라우저 개발자도구 Console/Network 탭에서 `api/*.php` 요청의 에러 메시지를 확인해주세요 (대부분 `config.php`의 DB 정보 오류입니다).

## license-guide.html (면허 취득 안내 위젯)

사용자가 제공한 위젯 파일(`__embed.html`)을 그대로 이식하고, 홈페이지 색상 변수(`css/style.css`의 `--color-*`)에 맞춰 위젯 내부의 색상 토큰만 재매핑했습니다. 레이아웃·계산 로직·데이터는 원본 그대로입니다.

## 색상 팔레트 (2026-09 개편)

수강료가 어디서 정해지는지 헷갈리기 쉬워 정리해 둡니다.

- **`license-guide.html`(수강생 화면)에는 계산식이 없습니다.** `api/license-data.php`(DB)에서 케이스별로 **저장된 금액을 그대로 표시**만 합니다. 화면에서 계산하는 건 ①합계 ②"교육시간이 0이면 해당 검정료도 면제" 판단, 이 둘뿐입니다.
- **계산식은 `admin-license.html`(관리자 화면)에만** 있습니다.
  ```
  비용 = 교육시간 × 시간당 단가        (calcCost 함수)
  학과 단가는 공통값(10,000원)을 쓰되, 면허별로 따로 지정하면 그 값이 우선
  ```
  관리자 화면에서 교육시간을 고치면 "자동" 모드인 케이스만 금액이 다시 계산되어 DB에 저장됩니다.
- **과거에 값이 틀어졌던 이유**: `MANUAL_DEFAULT_CODES`에 TM-01~04, B1-06이 "수동"으로 고정돼 있어서, 교육시간을 6시간→3시간으로 줄여도 금액(330,000원)이 그대로 남아 있었습니다. 지금은 36개 케이스 전부가 공식과 일치하도록 정리했고 이 배열을 비웠기 때문에, 앞으로는 시간을 고치면 금액이 따라옵니다.
- **요율표에 없는 면허 코드를 쓰면 검정료가 조용히 사라집니다.** `examFeeNumbers()`가 코드 앞부분(`TM-01`의 `TM`)으로 요율을 찾는데, 없는 타입이면 `null`을 반환해 검정료 칸이 통째로 안 나옵니다(CD-01이 실제로 이 상태였습니다). **새 케이스 코드를 만들 때는 반드시 `rates.types`에 같은 접두어를 추가**하세요 — `license-guide.html`, `db/license_default_data.json`, `admin-license.html` 세 곳 모두입니다.
- **검산 방법**: 저장된 금액이 `교육시간 × 단가`와 맞는지 한 번에 확인하려면, `license-guide.html`의 `DATA` 블록을 파싱해 모든 케이스를 대조해보면 됩니다. 이 방식으로 TM-01/02/03 도로주행비(330,000 → 165,000)와 GN 학과비 오류를 찾아냈습니다.
