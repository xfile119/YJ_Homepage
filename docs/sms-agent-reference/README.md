# SMS/카카오톡 발송 연동 참고자료

학원 학사서버(MSSQL)에서 쓰던 LG U+ SMS 에이전트(`LGUPlus_Agent_2.3.3_1_release`) 관련
자료를 검토하기 위한 임시 폴더입니다. 이 폴더 자체는 홈페이지에서 쓰이지 않고, 카카오톡/문자
발송 기능을 설계하기 위한 참고용 자료 보관소입니다.

## 올려주시면 좋은 파일

- 에이전트 설정 파일 (`*.ini`, `*.cfg`, `*.xml`, `config.*` 등)
  - **DB 접속 비밀번호, 인증키/API 키 등 민감정보는 반드시 지우거나 `****`로 마스킹한 뒤 올려주세요.**
- 실행/스케줄 관련 파일 (배치파일, 서비스 등록 스크립트 등)
- 매뉴얼/README 문서
- 로그 파일 샘플 1~2개 (있다면) — 실제 SQL 조회/상태값 갱신 패턴 파악용
- 학사 DB의 발송 큐/이력 테이블 스키마 (`CREATE TABLE` 스크립트 또는 컬럼 목록 캡처/텍스트)
- 그 테이블과 수강생 정보 테이블을 잇는 키 컬럼에 대한 설명
